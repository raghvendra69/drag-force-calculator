# drag-force-calculator
This calculator demonstrates how physical principles from fluid mechanics and aerodynamics can be translated into computational models using Python.
this program calculates drag force:

Fd = 0.5 × ρ × v² × Cd × A
Where:
ρ  = air density (kg/m³)
v  = velocity (m/s)
Cd = drag coefficient
A  = cross-sectional area (m²)
Drag force calculations are used in:
- Aerospace Engineering (aircraft and rocket design)
- Automotive Engineering (vehicle aerodynamics)
- Sports Engineering (cycling, racing optimization)
- Marine Engineering (ship resistance analysis)
- Civil Engineering (wind load on buildings)
